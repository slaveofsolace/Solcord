# Next-wave roadmap

This is research, not shipped V1 functionality. Names and concepts are original integrations unless a future provenance review approves a specific licensed source.

## Voice and audio

- **Mic Chain Doctor:** local clipping, noise-floor, device-change, and mute-mismatch diagnostics.
- **Voice Scenes:** per-server input mode, suppression, gain, and output-device presets. SteelSeries Sonar documentation only through supported public interfaces.
- **Speaker Guard:** local caps for sudden per-user volume spikes with explicit restore.
- **Voice HUD:** call duration, connection health, bitrate, and active device.
- **Call Handoff:** offer a return to the previous channel; never auto-join.

## Chat and media

- **Clipboard Studio:** clean links, images, Markdown, and filenames before paste.
- **Media Inspector:** local dimensions, codec, duration, color profile, and CDN facts.
- **Alt-Text Coach:** prompt for concise image descriptions; never auto-submit.
- **Unread Triage:** temporary local grouping of mentions, replies, watched threads, and priority DMs without message logging.
- **Composer Sandbox:** Markdown/code/embed preview without sending.
- **Quote Composer:** multi-message quotations with source links and explicit preview.

## Layout and recovery

- **Per-Guild Themes:** local token overrides bound to a server, with contrast checks.
- **Layout Scenes:** compact chat, media review, voice, and moderation layouts.
- **Focus Fade:** dim unrelated channels without erasing unread/mention state.
- **Local Data Vault:** encrypted private notes and exports through a reviewed secure-storage bridge.
- **Recovery Console:** safe-mode controls and sanitized logs without DevTools.

## Research boundary

The current BetterDiscord catalog demonstrates demand for call timers, volume controls, message splitting, image tools, permission viewers, activity toggles, and privacy utilities. SoulCord should integrate related workflows coherently rather than clone catalog plugins. No candidate advances without a controlling license, pinned revision, exact file list, cleanup review, runtime budget, and privacy/account-risk decision.
